# 0012. Product name: Carrel

- Status: Accepted
- Date: 2026-09-25

## Context

The working name "ZenSpace" was a placeholder. The owner wanted something calm and smart.

## Decision

**Carrel**: a library carrel is a small private desk for quiet study. Tagline draft:
"Your quiet place to learn."

Rejected candidates: Menya (a RICTA student program launched at UoK uses it), Stoa (existing
Stoic meditation app), Dwell (well-known audio Bible app and a magazine), Mull (an existing browser and waste app).

## Consequences

- Some people won't know the word. The tagline and onboarding explain it.
- **Still to verify before public launch:** domain availability, app store names, trademark
  search. A pre-launch learning platform called "Carrely" exists; the names are close but different.
